Copy of FW patch overview - newest available FW, Online approval/SD Patch possibility

info

Below you can find an overview based on the FW version which kind of patch can be applied

MST2 ZR EU

VW​

old FWnew FWHWMJOnline Approval/SD Patch possible
01xx0140H1x2015Yes, only with Navigation (2 SD Ports)
02xx0254H2x2016Yes, only with Navigation (2 SD Ports)
03xx0369H3x2017Yes, only with Navigation (2 SD Ports)
04xx0480H4x2018 (and newer)Yes, only with Navigation (2 SD Ports)

Seat​

old FWnew FWHWMJOnline Approval/SD Patch possible
02xx0253H2x2016Yes, only with Navigation (2 SD Ports)
03xx0369H3x2017Yes, only with Navigation (2 SD Ports)
04xx0480H4x2018Yes, only with Navigation (2 SD Ports)
05xx0516H5x2019 (and newer)No (eMMC only)

Škoda​

old FWnew FWHWMJOnline Approval/SD Patch possible
01xx0140H1x2015Yes, only with Navigation (2 SD Ports)
02xx0253H2x2016Yes, only with Navigation (2 SD Ports)
03xx0369H3x2017Yes, only with Navigation (2 SD Ports)
04xx0480H4x2018 (and newer)Yes, only with Navigation (2 SD Ports)

Some other Informations about not SD Card patchable Units​

Be aware that it is not possible to patch with SD card solution in some cases (FPK/VC is one of the possible reasons). The Online Approval exploit can not be used on these units. If you have any informations about the affected part numbers (or any other informations about it please let us know here).

Also on SEAT 05xx FW it is not possible to use the exploit. Only patching with direct eMMC read/write is possible.

How to find the data from your unit​

Take a look at the label on the unit.

Or check your FW version in the ServiceMode = long press at the Menu Button → SW Update

Only by checking the data in ServiceMode allows you to know the real/latest FW Version from your Unit.
