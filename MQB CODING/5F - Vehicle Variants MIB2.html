5F - Vehicle Variants MIB2

This information is stored in module 5F, long coding, bytes 00, 01, 02.

Decoding​

Brand​

  • x1 xx xx - Audi
  • x2 xx xx - Volkswagen
  • x3 xx xx - Skoda
  • x4 xx xx - Seat

  • xx xx x0 - Hatchback

  • xx xx x5 - Cabriolet
  • xx xx x6 - SUV
  • xx xx x8 - Minivan
