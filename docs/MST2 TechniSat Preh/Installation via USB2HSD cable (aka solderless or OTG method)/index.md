# Installation via USB2HSD cable (aka solderless or OTG method)

# **https://www.youtube.com/watch?v=elCH1vPrO7o**

The video above serves only for illustrating purposes. This "solution" was stolen by evaldas who wanted to sell it but failed. Orignal author is **Malec**.


**LIMITATIONS:** This method is only compatible with **cpu** and **cpuplus** units with one and two SD slots.

It will **not work** on **mainstd** units **without iMX6** chipset. Units without iMX6 have partnumbers like xxx03581\* and xxx03582\*. E.g 5Q0035819\*

This will also not work on **some cpuplus** units as drivers included into **custom_plus.ifs** are not compatible with all types of the units.
