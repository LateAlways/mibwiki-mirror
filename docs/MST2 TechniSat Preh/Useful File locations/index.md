# Useful File locations

Here you will find the path of useful files you will dealing with in case of need:

| Target | File path |
|----|----|
| SWDL | `/tsd/bin/swdownload/tsd.mibstd2.system.swdownload` |
| FEC | `/tsd/bin/swap/tsd.mibstd2.system.swap` |
| CP | `/tsd/hmi/tsd.mibstd2.hmi` |
| EL | `/tsd/etc/slist/signed_exception_list.txt` |
| Network config | `/tsd/etc/networking/pf.config` |
| Boot logo | `/tsd/etc/startanim/starup_x.boot` |
| Startup | `/tsd/bin/system/startup` |


Also see [here](https://mibwiki.one/doc/mounting-vmdk-in-qnx-vm-yztTMD3AqQ)
